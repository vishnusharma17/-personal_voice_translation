# Personal Voice Translation — AI Operating System

This package is the project brain and operating system for Antigravity.

## Product

A real-time personal voice translation platform:
the user speaks naturally in their language and the other participant hears only the translated language in the user's authorized voice.

## How to use

Open this package as the project foundation in Antigravity and say:

`Start`

The Master Agent will read the minimum required context, inspect the actual repository, identify the next task, build it, verify it, and checkpoint the work.

Later you can say:

`Continue`

and it will resume from `STATUS/CURRENT.md` and `STATUS/HANDOFF.md`.

## Single-source-of-truth structure

- `AGENTS.md` — master AI operating instructions
- `BRAIN/` — product, architecture, roadmap, permanent decisions
- `RULES/` — safety, security, privacy, voice, efficiency
- `WORKFLOWS/` — how work is planned, built, reviewed, tested, released
- `STATUS/` — current progress and resume checkpoint
- `PLANS/` — durable plans only when needed
- `docs/` — specialist role/reference material

There are intentionally no duplicate progress/history/context files.

## Important

This package contains the AI operating system, not the final application implementation.

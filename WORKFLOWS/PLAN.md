# Plan Workflow

Use for new or cross-system work.

1. Define the actual outcome.
2. Check current status.
3. Inspect existing implementation.
4. Identify affected subsystems.
5. Select the smallest relevant specialist set.
6. Define boundaries and acceptance criteria.
7. Identify security/privacy impact.
8. Define tests.
9. Record the plan in `PLANS/` only for work large enough to need a durable plan.

Do not write a large plan for a trivial change.

# Review Workflow

Review only the dimensions relevant to the change.

Product:
- does it solve the intended problem?

Engineering:
- architecture, maintainability, failure paths.

Voice:
- identity, naturalness, prosody.

Translation:
- meaning, intent, tone.

Realtime:
- latency, interruption, reconnect, session isolation.

UX:
- clarity, trust, simplicity.

Security/privacy:
- unauthorized access, leakage, retention, abuse.

Fix critical issues before moving forward.

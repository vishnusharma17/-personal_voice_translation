# Definition of Done

A task is complete only when applicable items are true:

- [ ] Requirement implemented.
- [ ] Existing behavior remains correct.
- [ ] Relevant verification passed.
- [ ] Error paths considered.
- [ ] Security/privacy impact considered.
- [ ] No secret introduced.
- [ ] No unnecessary duplicate abstraction/file created.
- [ ] Documentation updated if durable behavior changed.
- [ ] `STATUS/CURRENT.md` updated when meaningful.
- [ ] User-facing result is accurately reported.

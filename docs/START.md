# Start Here

The user should be able to say only:

`Start`

The Master Agent must then:
1. load the master instructions;
2. load current status;
3. understand the product and architecture;
4. inspect the actual repository;
5. identify the next unblocked task;
6. execute it;
7. verify it;
8. update the checkpoint;
9. continue when the next step is unambiguous.

The user should not have to repeatedly explain the project.
